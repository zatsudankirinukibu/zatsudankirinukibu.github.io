プライバシーポリシー

対象：YouTube チャンネル「ホロ雑談切り抜き部」の運営者が使う個人用ツール「kirinuki-upload」（以下「本ツール」）

1. 利用者

本ツールを使うのはチャンネルの運営者本人だけです。第三者にアカウントの連携を求めることはありません。

2. 取得する情報と使い方

本ツールは、運営者が許可した範囲で、YouTube API Services を通じて運営者自身のチャンネルについて次の情報を扱います。

  • 動画のアップロード・公開設定（運営者が確認した動画の投稿に使います）
  • 運営者の動画に付いたコメント（運営者への通知に使います）
  • 運営者のチャンネルの統計（再生数・視聴時間など。運営の改善に使います）

これらの情報は運営者のパソコンの中でだけ保存・利用し、第三者への提供・販売はしません。

3. 保存と削除

認証情報と取得したデータは運営者のパソコンに保存します。連携は Google アカウントの「サードパーティ製のアプリとサービス」（https://myaccount.google.com/connections）からいつでも解除でき、解除後は本ツールから YouTube のデータにアクセスできなくなります。

4. YouTube・Google のポリシー

本ツールは YouTube API Services を利用しています。YouTube 利用規約（https://www.youtube.com/t/terms）と Google のプライバシーポリシー（https://policies.google.com/privacy）も適用されます。
